# DSH Desktop 图标

[English](README.md) | 中文

这枚独立的社区项目标识表示一条原创模块化鲸鱼，其三个可交换插件节点会路由到一个中心 Harness 核心。它刻意不复制 DeepSeek 官方鲸鱼轮廓，也不包含 ClawRouters 品牌标识。

`icon-source.png` 是带可移除色键背景的原始生成图稿。`icon-transparent-source.png` 是已处理 alpha 的源图。`icon.png`、`icon.icns` 和 `icon.ico` 是用于打包的跨平台资源。

源图稿由 OpenAI ImageGen 为本仓库生成，然后在本地进行 alpha 处理、缩放和格式转换。提示词要求一条由模块化板件构成的原创几何鲸鱼、三个路由插件节点、深靛蓝图块与青色／珊瑚色点缀，不含文字、第三方 logo 或仿制的商标轮廓。
