# DSH Desktop icon

English | [中文](README.zh.md)

This independent community-project mark represents an original modular whale fitted with three interchangeable plugin nodes routed through one central Harness core. It intentionally does not reproduce the DeepSeek official whale silhouette or any ClawRouters brand mark.

`icon-source.png` is the original generated artwork on a removable chroma-key background. `icon-transparent-source.png` is the alpha-matted source. `icon.png`, `icon.icns`, and `icon.ico` are the packaged cross-platform assets.

The source artwork was generated with OpenAI ImageGen for this repository, then alpha-matted, resized, and converted locally. The prompt required an original geometric whale built from modular plates, three routed plugin nodes, a deep indigo tile, cyan/coral accents, no text, and no third-party logo or copied trademark silhouette.
